# MemoDeck

Веб-приложение для интервального изучения иностранных слов, терминов и определений с помощью интерактивных двусторонних карточек. Проект разработан на чистом JavaScript с использованием нативного DOM API и модульной архитектуры без сторонних фреймворков.

## ✨ Основные возможности

* **Управление колодами:** создание собственных тематических наборов карточек и их удаление.
* **Редактор карточек:** добавление и удаление пар «Слово / Термин — Перевод / Определение» внутри каждой колоды.
* **Режим тренировки:**
  * Интерактивный 3D-переворот карточки по клику или нажатию клавиши `Пробел`.
  * Оценка знания («Знаю» / «Повторить») с динамическим прогресс-баром.
  * Финальный экран статистики с возможностью запустить повторную тренировку только по сложным словам.
* **Локальное хранение данных:** все колоды и прогресс автоматически сохраняются в `localStorage` браузера (при первом запуске доступны предустановленные демо-колоды).

---

## 🛠 Технологии и архитектурные решения

* **HTML5:** семантическая разметка, использование тега `<template>` для безопасного клонирования DOM-элементов.
* **CSS3:** адаптивная верстка (Flexbox / Grid), CSS-переменные, 3D-трансформации (`perspective`, `transform-style: preserve-3d`) для анимации карточек.
* **JavaScript (ES6+):**
  * Нативная работа с DOM (`querySelector`, `createElement`, `classList`, `dataset`, `textContent`).
  * Делегирование событий для оптимизации обработчиков кликов.
  * Модульная структура (`import` / `export`) с разделением зон ответственности.
  * Web Storage API (`localStorage`) для сохранения состояния.
